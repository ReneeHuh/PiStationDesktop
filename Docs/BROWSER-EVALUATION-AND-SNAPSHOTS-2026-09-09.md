# Agent JavaScript evaluation and rich browser snapshots

WEB-16 and WEB-18 use the retained browser workspaces introduced by WEB-13/14/15. The source comparison baseline is local T3 commit `0a590fa01af66ec135d2ebf2d5542b08a37dc275`. Wire protocol **50** requires matching host and desktop builds.

## Evaluation

`pistation_browser` accepts `action: evaluate`, `expression`, optional `tabId`, `awaitPromise` (default true), and `timeoutMs` (default 5,000; 100–20,000). It evaluates in the target page's main frame. The result is `{type,value}`; undefined is explicitly `{type:"undefined",value:null}`. Non-JSON results such as BigInt, NaN, functions and remote handles return an error. `returnByValue`, if supplied, must be true. Expressions are limited to 32,000 characters and the complete request envelope remains limited to 64 KiB. Results, including their type/value envelope, are limited to 64,000 UTF-8 bytes. Exceptions return bounded details.

Evaluation requires **Interact** in the Pi extension, host and desktop. Inspect-only access does not allow arbitrary scripts, including scripts that appear read-only. Existing environment/thread ownership, pinned tab targeting, deletion, closure and disconnect rules apply. Result validation runs inside the page before CDP serialization, which can otherwise erase a Promise or DOM node's type and silently return `{}`. Source runs once through indirect global evaluation; use properties on `window` for persistent scratch state rather than relying on REPL-style `let`/`const` declarations.

WebView2 executes through CDP `Runtime.evaluate` with an engine timeout. The desktop also bounds its wait and sends `Runtime.terminateExecution` when an unfinished execution is cancelled or times out. It drains termination before another agent operation can start on that tab. If termination cannot be confirmed or the evaluation does not settle, the unresponsive WebView is closed; close and reopen that tab to recover. Navigation cancels evaluation against the previous document. Cancellation does not undo applied page changes or guarantee cancellation of independently scheduled timers, fetches or other page work. Result bounds are transport limits, not a JavaScript memory sandbox.

These semantics use the [Chromium Runtime protocol](https://chromedevtools.github.io/devtools-protocol/tot/Runtime/) through [WebView2's CDP API](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2.calldevtoolsprotocolmethodasync). T3 uses the same evaluation command but its reviewed path has a broker response deadline without explicit execution termination. Its exposed `returnByValue:false` option drops the remote object handle in the executor; PiStation only exposes serialized values.

## Snapshot

`action: snapshot` requires **Inspect** or Interact. It returns URL, title, loading state, visible text, interactive elements (name, explicit role, selector and geometry), a projected accessibility tree, console diagnostics, failed network requests, action history and screenshot metadata. The Pi tool delivers the PNG as image content alongside the JSON. This replaces the old basic `elements` snapshot shape with `interactiveElements` in protocol 50.

Text is limited to 20,000 characters. DOM collection scans at most 5,000 candidate elements and returns at most 200. The accessibility request has depth 8; the projected result has at most 250 nodes and retains node IDs, child references, backend DOM IDs, roles, names, descriptions, values and bounded properties. A CDP tree response above 4,194,304 characters is omitted before parsing. CDP itself offers no breadth/byte cap on that response.

The console, failed-request and action buffers retain at most 200 entries each. Diagnostics start when automation first attaches to the tab; `diagnosticsSinceUtc` reports that boundary. Disabling access or disconnecting clears the buffers and removes event listeners. HTTP status 400+ and loading failures are retained; successful traffic, request headers, cookies and response bodies are not collected. Diagnostic network URLs use the logical host URL for forwarded previews. Action history contains operation names, status, timestamps and bounded errors, without copying script expressions or typed inputs.

Section byte budgets keep the complete JSON result within 256 KiB. `truncated` flags identify omitted data. Diagnostics and action history favor recent entries when the byte budget is reached. Screenshots preserve aspect ratio at a maximum width of 1,280 pixels and remain within the existing 4 MiB PNG limit. A snapshot spanning navigation or exceeding its deadline fails rather than mixing documents.

T3's collector combines DOM inspection, `Accessibility.getFullAXTree`, debugger events, action history and `capturePage`. PiStation follows that combination through WebView2, with explicit accessibility and total payload budgets. The selector is a best-effort CSS target; neither the DOM visibility filter nor the accessibility projection establishes that an element is unobscured or inside the viewport.
